# 60ketchup
60% keyboard gasket-mount with hot-swaps
<img width="1976" height="766" alt="image" src="https://github.com/user-attachments/assets/4fdcb921-5500-49d3-be67-be6802d177af" />
most effort-keyboard project I made

- 61 keys (number keys, no arrows keys)
- hot-swaps
- gasket-mount

I started with project somewhat weeks ago after finishing my first keyboard. There was so many improvements and changes I could of make if I made another keyboard. I tried to make a curved Alice, split wired keyboard. Unfortunately, I ended up with not many days to work on it and time was running out before the program ended. I had to edit my schematics and PCB to fit the new keyboard criteria. I spent the rest of the days just then working on the PCB and github. 

Overall, this project was fun and gave me opportunities to practice and learn using Fusion360 and KiCad and the general understanding of how keyboards are made. Learning how to create a keyboard and having a finished product that I was satisfied with was really nice. Some of the things that were a huge process or took a long time to learn / work on was reediting work to a new keyboard layout, tracing all my components, learning how to create a gasket mount that was stable, and creating my bill of materials list. My files are found in PCB and KiCad.
